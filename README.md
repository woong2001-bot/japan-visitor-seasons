# 일본을 찾는 계절

한국인은 언제 일본을 가장 많이 방문하며 대만·미국과 어떤 차이가 있을까?

[공개 대시보드](https://jnto-visitor-seasons.streamlit.app/) · [JNTO 원자료 안내](https://www.jnto.go.jp/statistics/data/visitors-statistics/) · [사용한 공식 Excel](https://www.jnto.go.jp/statistics/data/_files/20261118_1615-5.xlsx)

## 자료와 검산

2026년 11월 18일 공개본에서 2023~2025년 시트의 韓国·台湾·米国 행과 1月~12月 열을 추출했습니다. 단위는 방문 연인원이며 관광·상용 등 방문 목적 전체를 포함합니다. 한 행은 한 연도·한 월·한 시장입니다. 108행에 중복·결측이 없고 9개 시장·연도의 월별 합계가 원본의 累計와 일치합니다.

|연도|한국|대만|미국|
|---|---:|---:|---:|
|2023|6,958,494|4,202,434|2,045,854|
|2024|8,817,765|6,044,316|2,724,594|
|2025|9,459,711|6,763,424|3,306,820|

## 실행

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 코드 읽는 순서

1. `load_data()`가 앱 옆 CSV를 읽고 월을 계절로 변환합니다.
2. `isin()`은 고른 연도·시장에 해당하는 행을, `between()`은 고른 월 범위의 행을 남깁니다. 둘을 적용한 표가 `view`입니다.
3. 카드와 차트는 이 표로 계산합니다. 월별 누적 막대는 여러 해의 같은 달을 더합니다. 계절 비중은 선택된 시장별 계절 합계를 그 시장의 선택 기간 합계로 나눕니다. 겨울은 각 역년 1·2·12월입니다.
4. 연월별 선은 달력 순서로 그립니다. 선택에서 빠진 달은 빈칸으로 두어 실제 관측치가 없는 구간에 선이 이어지지 않습니다.

## 결과 읽기

한국은 3년 모두 12월, 미국은 3년 모두 6월이 최고였습니다. 대만은 10월·6월·8월로 바뀌었습니다. 3년을 합쳐 계절별로 비교하면 한국은 겨울 28.7%, 대만은 여름 27.8%, 미국은 봄 28.7%가 최고입니다. 연도별 방문객이 많은 해가 통합 비중에 더 크게 반영됩니다. 반복 방문·방문 목적·예약 시점·광고 반응을 개인별로 구분할 수 없어 프로모션 시기 제안은 검증할 가설로 해석합니다.
